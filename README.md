# Cine Talkies

A responsive movie ticket booking landing page built using HTML and CSS. The website features a modern user interface with sections for movies, services, customer testimonials, and booking information.

## Features

* Responsive Design
* Modern UI Layout
* Movie Showcase Section
* Customer Testimonials
* Call-to-Action Buttons
* Mobile-Friendly Design

## Technologies Used

* HTML5
* CSS3
